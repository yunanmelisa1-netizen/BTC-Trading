1

Download Template

Klik tombol "Template" di header untuk download file Excel kosong yang sudah berformat sesuai kolom dashboard.

2

Kolom Wajib Diisi

Tanggal, Arah (LONG/SHORT), Tipe, Harga Entry, Harga Close, Lot ($), Profit/Loss ($)

3

Strategi Entry (1 Lot)

Modal $1000 ÷ 10 = $100 per lot. Average down dengan 2x lot jika BTC turun 2.000–3.000 poin.

4

TP & SL

TP1 = +0.5% | TP2 = +1.0% | TP3 = +2.0% dari entry. SL = -1.5% dari entry.

5

Compound Profit

Setiap profit langsung ditambah ke modal aktif → lot size berikutnya otomatis membesar.

Upload Excel

Setelah isi data di Excel, klik "Upload Excel". Dashboard otomatis sinkron semua data.

7

Download Data

Klik "Download" untuk simpan semua trade ke file Excel baru.
